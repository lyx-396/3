# 飞机大战示例

这是一个使用 Pygame 编写的简易飞机大战示例。玩家只控制一架战机，拥有比单个敌机更多的血量。画面中会持续生成敌机，敌机数量更多且会发射子弹。玩家需要灵活移动并击落敌机，存活越久、得分越高。

## 运行方式

1. 安装依赖：
   ```bash
   pip install pygame
   ```
2. 运行游戏：
   ```bash
   python plane_battle.py
   ```

## 操作说明

- 方向键移动我方战机。
- 空格键发射子弹。
- 游戏结束后按 `R` 可重新开始。

玩家血量和敌方总血量会在屏幕上方显示，我方战机血量更高但数量只有一架，敌机血量较少但数量更多。
